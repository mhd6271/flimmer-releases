# Flimmer – Downloads

Fertige Versionen von **Flimmer**: YouTube-Videos ansehen ohne Werbung, mit SponsorBlock, DeArrow, Live-Chat,
Abos ohne Google-Konto und Mini-Player – für macOS, Windows und Linux.

➡️ **[Neueste Version herunterladen](https://github.com/mhd6271/flimmer-releases/releases/latest)**

| System | Datei |
|---|---|
| macOS (Apple Silicon) | `Flimmer-…-macOS-arm64.zip` – entpacken, in „Programme“ ziehen; beim ersten Start Rechtsklick → Öffnen |
| Windows | `Flimmer_…_x64-setup.exe` (oder `.msi`) – SmartScreen: „Weitere Informationen“ → „Trotzdem ausführen“ |
| Linux | `.AppImage`, `.deb` oder `.rpm` |

Die Apps sind (noch) nicht von Apple bzw. Microsoft signiert, daher die Warnungen beim ersten Start.

**Updates:** Flimmer prüft selbst auf neue Versionen (Einstellungen → Updates) und installiert nur Pakete mit
gültiger Signatur. Die Dateien `latest.json` und `*.sig` in den Releases sind dafür da.

Dieses Repo enthält nur die fertigen Programme, nicht den Quellcode.
Flimmer ist mit YouTube und Google nicht verbunden.
